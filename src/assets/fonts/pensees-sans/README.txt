Pensees Sans
============

An instance of Mona Sans (The Mona Sans Project Authors, SIL Open Font
License 1.1, see OFL.txt), made by scripts/instance-fonts.mjs from the
@fontsource-variable/mona-sans Latin and Vietnamese files.

The width axis is pinned at 112%, the only width the publication sets; the
weight axis is kept whole. Nothing else is changed: the same glyphs, the same
outlines at that width, the same copyright, licence, designer and trademark
records.

Mona Sans reserves the name "Mona": a modified version may not be presented
under it, so this instance is named Pensees Sans.
